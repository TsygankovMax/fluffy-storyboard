# Что отдавать художнику

В игре **нет ни одного нарисованного файла**. Буквы, доска, лунки, шахты, фоны,
кнопки, попапы - всё это рисует код на канвасе каждый кадр. Исходников в смысле
«папка с PSD» не существует и никогда не существовало: это решение с самого
начала, чтобы арт можно было заменить целиком, не трогая игру.

Поэтому «отдать элемент» здесь значит вызвать ту же функцию отрисовки, которой
игра рисует его на экране, на отдельном холсте нужного размера. Всё в этой папке
снято именно так: не скриншоты и не мокапы, а сама игра, только по одной вещи за
раз и в четыре-пять раз крупнее, чем на телефоне.

## Что здесь лежит

| путь | что это |
|---|---|
| `letters/png/*.png` | **58 букв**, по файлу на букву, холст 1080x1080, прозрачный фон. Латиница `lat-*`, кириллица `cyr-*`. |
| `letters/psd/*.psd` | те же 58 букв, **по пять слоёв в каждой**: обводка, тело, блики, глаза, рот. |
| `letters.psd` | все 58 букв одним листом 2400x1440, по слою на букву, две группы по алфавитам. |
| `letters-all.png` | тот же лист одной картинкой с альфой. |
| `elements/*.png` | **97 элементов игры**: фоны, лунки всех видов, шахты, башня, шарики, ключи, иконки предметов, бустеры, интерфейс. |
| `elements/index.html` | контактный лист - открыть в браузере и увидеть весь пакет разом. |
| `screens/*.png` | **9 экранов целиком**, 720x1280: доска на четырёх уровнях, попап механики, настройки, взведённый бустер, экран победы, новый предмет. |

Буквы на общем листе идут по кругу через все десять цветов игры, чтобы каждый
скин был виден. Цвет - это параметр отрисовки, а не отдельная картинка: любую
букву можно пересобрать в любом из десяти.

## Три важных предупреждения

**1. Двенадцать элементов в игре сейчас чужие.** Сундук, монета, замок, палец
подсказки, три бустера и четыре иконки предметов стоят вырезками из записи
*оригинальной* игры, как измерительная заглушка. В пакет они не попали: вместо
них снят наш собственный процедурный вариант той же вещи. Силуэт и роль он
показывает верно, а рисовать их всё равно заново.

**2. Часть мебели есть только на экранах.** Плита заголовка, кнопка настроек,
поднос бустеров со своей лужей света, палец подсказки и значки в тумблерах
рисуются внутри сцены, а не отдельной функцией, поэтому вырезать их на
прозрачный фон нечем. Они в папке `screens/` - в композиции, где они и нужны.

**3. На шарике сверху сидит буква.** Это механика, а не украшение: игрок читает
слово уровня по шарикам. Любая новая форма шарика должна пережить букву поверх
себя и остаться читаемой. Всё остальное можно менять свободно.

Ещё две вещи, которые видны только в игре и легко ломаются красивым артом:
лунка должна читаться на телефоне при 60 пикселях, и десять цветов должны
отличаться друг от друга, включая белый и жёлтый рядом.

## Как пересобрать

Нужен запущенный дев-сервер: буквы и элементы существуют только как код, и рисует
их браузерный канвас.

```
npm run dev -- --port 5388
node tools/letters-pack.mjs      # -> letters/png и letters/psd
node tools/letters-psd.mjs       # -> letters.psd, общий лист
node tools/elements-pack.mjs     # -> elements/ и контактный лист
node tools/screens-pack.mjs      # -> screens/, экраны целиком
node tools/art-index.mjs         # -> index.html, входная страница
node tools/headless.mjs http://127.0.0.1:5388/ \
  --eval-shot @tools/letters-sheet.js docs/art-handoff/letters-all.png
```

Разрешение везде задаётся одной цифрой в соответствующем `*-page.js`: `SIZE` для
букв, `CELL` для кусков доски. Буквы и вся геометрия векторные по своей природе,
так что увеличение бесплатное и не мылится.

Сборку PSD делает `ag-psd`, она стоит **только в devDependencies** и в сборку
игры не попадает.

## Проверка

Три вещи проверяются машиной, а не глазом:

- **Слои складываются обратно в букву.** Пять шагов, положенные друг на друга,
  сравниваются с одним вызовом без разбиения - на каждой из 58 букв, до
  последнего канала. Расхождение обязано быть нулевым, иначе `letters-pack.mjs`
  падает и пакет не собирается.
- **Пустых картинок нет.** Если функция отрисовки ничего не нарисовала, элемент
  уехал бы в пакет прозрачным квадратом; `elements-pack.mjs` такие называет
  поимённо и падает.
- **PSD читается посторонней программой.** `psd-tools` на питоне (другая
  реализация, не та, что писала) открывает файлы, и лист, склеенный заново
  **только из слоёв**, совпадает с прямым рендером игры. В самом Photoshop файлы
  не открывали: его на этой машине нет.

## Если художник отдаёт арт обратно

Принимаем PNG с альфой или SVG. Дальше картинки кладутся в `src/assets/` и
подменяют процедурную отрисовку по одной - именно для этого игра с самого начала
и не зависит от арта.
